# FujiNet Professional Arcade Programmers Handbook

The FujiNet programming manual for the Bally Arcade/Astrocade: an
in-depth tutorial on the cartridge mailbox (a network adapter on a
port that cannot write), client libraries in Z80 assembly and Z88DK C,
a complete reference for every Fuji-device and network-device command
the platform answers, and five worked programs — NETCAT, TEXAS
HOLD'EM, BATTLESHIP, FUJITZEE, CONFIG — with their full listings.

Typeset in the style of the 1977 *Bally Home Library Computer Owners
Manual* (`../learn/`): landscape half-letter booklet, cream stock,
black + Bally red, Helvetica-era heads, red CAUTION boxes, dot-leader
lists, TV-screen figures drawn in the clients' own 4×6 font.

## Build

Requires Typst 0.15+ and the vendored fonts:

```
make            # -> fujinet-programmers-handbook-astrocade.pdf
make preview    # -> preview/pNNN.png at 110 ppi
make watch
make font       # regenerate fonts/AstrocadeScreen.ttf (needs fontforge)
```

`fonts/AstrocadeScreen.ttf` is generated by `tools/make_screen_font.py`
from the netcat 96-glyph 4×6 font art (`listings/netcat/font.inc`) and
committed, so a normal build does not need fontforge.

## Sources of truth

Every address, opcode, struct offset and listing is transcribed from
the live project sources and verified against them:

| Source | Commit | Provides |
|---|---|---|
| `fujinet-firmware` | `20e89ead5` | `pico/astrocade/` — `fuji_mailbox.h` (the mailbox spec), testroms, RP2040 firmware; `lib/device/fujiDevice` + mixins and `lib/device/rs232` (the command dispatch tables); `FujiBusPacket` |
| `netcat/astrocade` | `b269a3d` | NETCAT |
| `fujinet-texasHoldEm/astrocade` | `6ed0b6e` | TEXAS HOLD'EM |
| `fujinet-battleship/astrocade` | `5b1f976` | BATTLESHIP |
| `fujinet-fujitzee/astrocade` | `d20d20e` | FUJITZEE |
| `fujinet-config/astrocade` | `d551e1a` | CONFIG |
| `z88dk` | `3bd06cad` | the `+astrocde` target the C chapter builds with |

`listings/` holds byte-identical snapshots of the five programs'
sources at those commits (shared files deduplicated into `common/` and
`games-common/`), which Appendix C `read()`s at build time — plus
`listings/c-demo/`, the working Z88DK C project of Chapter 6 and
Appendix D, verified end to end under MAME against a live
fujinet-pc-rs232 BoIP listener (`make -C listings/c-demo smoke`).
