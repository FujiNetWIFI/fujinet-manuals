# FujiNet ColecoVision — Programmers Handbook

The FujiNet programming manual for the **ColecoVision**: the cartridge mailbox
tutorial, the Z80 assembler and Z88DK C client libraries, the complete command
reference for every device the FujiNet answers, and four worked programs
(NETCAT, 5 CARD STUD, BATTLESHIP, CONFIG) with full listings.

It is typeset in the **FujiNet engineering series** house style, matching
*The FujiNet Network Protocol Handbook* and the *Platform Bring-Up Guide* —
single-column US-Letter, Nimbus Roman body, Nimbus Sans heads, Source Code Pro
listings, FujiNet-red accents, sticky headings (a heading is never stranded from
its content), and strict widow/orphan control.

Every address, opcode, struct offset and code fragment is transcribed from the
live project sources and verified against the firmware and a running adapter;
the sources-of-truth table below carries the exact commits.

## Building

Requires [Typst](https://typst.app) 0.15 or newer.

```sh
make            # -> fujinet-programmers-handbook-coleco.pdf (104 pp)
make watch      # rebuild on save
make preview    # PNG per page at 110 ppi, into preview/
make font       # regenerate fonts/ColecoScreen.ttf (needs fontforge)
```

Fonts ship in `fonts/`: **Nimbus Roman** (body), **Nimbus Sans** (heads),
**Source Code Pro** (all code), and **Coleco Screen** — a pixel-outline TTF
generated by `tools/make_screen_font.py` from the 5 Card Stud port's 8×8 screen
font (`listings/5cardstud/coleco/font.bin`), used for the on-screen mockups and
committed so a normal build needs no fontforge.

## The example programs

Two programs in this book were written for it and verified end to end in the
grafted MAME against a live `fujinet-pc` (bus-over-IP on `127.0.0.1:9995`):

- **`listings/asm/`** — `fujimail.inc`, the mailbox in pure Z80 assembly, and
  `acfg.asm`, a hand-written cartridge that runs `GET_ADAPTERCONFIG_EXTENDED`
  and prints the SSID, IP and firmware version. Build with `./build.sh`
  (needs `z88dk-z80asm`); it pads to 32768 bytes and stamps the `FUJI` claim.
- **`listings/netcat/`** — a terminal for the `N:` device (a scrolling pane,
  the on-screen keyboard, `NET_OPEN`/`STATUS`/`READ`/`WRITE`/`CLOSE`). Build
  with `./build.sh` (needs `zcc`, `os7lib`, and the shared library in
  `listings/common/`).

The other listings are vendored verbatim from their repositories (see below).

## Sources of truth

Everything in the handbook is transcribed from these, at these commits:

| Source | Path / repo | Commit |
|---|---|---|
| Mailbox spec, firmware, MAME device, testrom | `fujinet-firmware/pico/coleco` | `d1e89c21e` (branch `colecovision-bringup`) |
| Portable C library, ColecoVision bus | `fujinet-lib-experimental` | `dc399ec` (branch `coleco-target`) |
| 5 Card Stud (ColecoVision port) | `fujinet-5cardstud` | `f2b5298` |
| Battleship (ColecoVision port) | `fujinet-battleship` | `c413cba` |
| FujiNet Go Coleco Desktop | `fujinet-go-coleco-desktop` | `e6db9ec` (v0.2.0) |
| os7lib (OS-7 BIOS binding) | `os7lib` | `a6254e8` |
| Z88DK (`zcc`, `z88dk-z80asm`) | `z88dk` | `3bd06cad56` |

CONFIG is documented from the firmware's `testrom/fujicfg.c` — the working
browse-and-boot client the cartridge serves today, whose own header notes it is
the stand-in for the eventual `fujinet-config/coleco` port. There is, as of
this writing, no ColecoVision port in `fujinet-config`.

## Wiki edition

`wiki/FujiNet-Programming-Guide-for-the-ColecoVision.md` is the GitHub-wiki
condensation of this handbook: the same section order, ASCII in place of the
Typst diagrams, the command chapters as tables, and one paragraph per program.
It is maintained by hand alongside `manual.typ`; when the two disagree, the
firmware sources win. Its home is the fujinet-firmware wiki.
