# FujiNet Manual for the H89 FujiNet — Operation

The end-user manual for the **H89 FujiNet** card (H89-ESP32-FUJINET, V1.1,
reworked for fujinet-firmware #2042, without its data 74LVC245 for #2232;
hardware by Joseph Travis, layout and schematics by Norberto Collado). This is
the third edition; the second covered the card with U3, the first the V1.0
card. It covers:

- installing the card;
- checking it with a program keyed into the monitor;
- the H89 port of FujiNet CONFIG;
- the FNDISK drivers that give HDOS and CP/M the FujiNet's eight drives;
- the same ground as the other FujiNet user manuals: WiFi, hosts, the microSD
  card, the web page, firmware updates, troubleshooting, specifications,
  circuit description, parts list.

`fujinet-h89-operation-manual.pdf` is the book.

## House style

A tribute to Heath's 1979 *Manual for the Digital Computer Model H88 —
Operation* (595-2268-02; scan in `../learn/`):

- **Page.** US Letter in two columns. The running head is a badge on the
  gutter side, with a long rule out to "Page N-M" on the outer side, and the
  page numbers count within each chapter.
- **Heads.** Chapter titles are big Century Schoolbook Bold capitals at the top
  left of a right-hand page. Section heads are centred, over balanced columns.
- **Steps and notes.** "( )" check-off steps; NOTE:, CAUTION: and WARNING:
  run-ins; a boxed IMPORTANT NOTICE.
- **Tables and drawings.** Dot-leader specifications; CONDITION / POSSIBLE CAUSE
  troubleshooting charts; Helvetica parts lists and Pictorial captions.
- **Typing.** What you type is underlined, and RETURN is a circled arrow.
- **Covers.** The gold cover with a brown three-tone picture and a white label;
  the gold back cover with its yellow band.

The FujiNet badge stands in for Heath's, and there are no Heath marks. A
not-affiliated notice is on the inside front cover.

## Building

```sh
make            # the PDF: needs typst 0.15 and the fonts in fonts/
make preview    # PNG pages in preview/
make check      # stranded lines, margins, no fallback fonts
```

Everything the PDF needs is committed:

- `screens/*.json` are the captured screens.
- `data/*.json` are the keyed-in programs as assembled.
- `fonts/`, `images/`.

These targets regenerate them:

| Target | Rebuilds | Needs |
|---|---|---|
| `make acctest` | `data/acctest.json` from `test/acctest.asm` | z88dk's `z88dk-z80asm` |
| `make verify` | keys the acceptance test into MTR-88, MTR-89 and MTR-90 (444-84 and 444-142) and checks the display, plus the failure cases and the MTR-90 port check | FujiNet Go H89 and its ROMs |
| `make boot-disks` | an HDOS 2.0 disk with FN.DVD; a 62K CP/M 2.2.04 | fujinet-h89, FujiNet Go H89 |
| `make shots` | every screen in the book | the above, fujinet-config, z88dk |
| `make cover` | `images/cover-board.png` | ImageMagick |
| `make font` | `fonts/H19Screen.ttf` from the 444-29 ROM | fontforge, MAME's `heath_tlb.zip` |

## How the pictures are made

- **Screens.** Every screen and session is captured from the real programs on
  FujiNet Go H89's headless machine. That is VirtualH89, the 82C55 card and the
  FujiNet firmware in-process; see `tools/rig.sh`, `tools/shots-*.sh` and
  `tools/run-acctest.sh`. Each capture is read back cell by cell against the H19
  character ROM (`tools/ppm2cells.py`) and set in the H19 Screen font. The
  emulator's stand-in WiFi values are replaced with an example network by
  `tools/screenfix.py`; FIGURES.md says which screens.
- **The acceptance test** is `test/acctest.asm`. `tools/mkacctest.py` assembles
  it and writes the octal table and the listing the book prints, so the book
  can't carry a byte the assembler didn't make.
- **Drawings** are in `figs.typ`, measured from `images/photo/board.jpg`, the
  KiCad render of the V1.1 card.
