# FujiNet Video Computer System — Programmer's Handbook

The FujiNet programming manual for the **Atari 2600**: the cartridge window and
the mailbox, the cartridge-composed text display, living in 128 bytes of RAM,
the 6502 library and batari Basic on the same mailbox, seven worked programs in
both languages, the complete command reference for every device the adapter
answers and every operation the cartridge itself performs, a bank-by-bank
walkthrough of Battleship, and the things that cost real time.

It is typeset after the 1977 *Video Computer System Owner's Manual*: a
half-letter booklet, Helvetica, numbered colour section bands with the numeral
in a black block at the outer edge, bold NOTE and IMPORTANT paragraphs between
thin blue rules, a SYMPTOM / PROBABLE CAUSE AND REMEDY checklist, and a Parts
List. The cover wordmark and the numerals are set in Harry Fat. Ragged right
throughout, with strict widow and orphan control.

## Building

Requires [Typst](https://typst.app) 0.15 or newer.

```sh
make            # -> fujinet-programmers-handbook-2600.pdf
make watch      # rebuild on save
make preview    # a PNG per page at 110 ppi, into preview/
make font       # regenerate fonts/VCSScreen.ttf (needs fontforge)
make listings   # rebuild every program (AS, dasm, batari Basic)
make shots      # re-capture every screenshot from MAME + fujinet-pc
make check      # snippet build check, command coverage, stranded lines, fonts
```

Fonts ship in `fonts/`: Helvetica (body and heads), Nimbus Sans Italic
(emphasis), Source Code Pro (code), Harry Fat (cover and numerals), and
**VCS Screen**, a pixel-outline TTF generated by `tools/make_screen_font.py`
from the cartridge's own 3×5 font table (`tools/vcsfont.py` in the bring-up),
used for the TV mockups.

The book compiles with `--ignore-system-fonts`, because the system's Harry
family carries two cuts at the same weight.


## The programs

Every program was built and run in the FujiNet MAME cartridge model against a
live `fujinet-pc-rs232` (bus-over-IP on `127.0.0.1:9995`), and checked by a
harness rather than by eye:

| Program | Assembly | BASIC | Harness |
|---|---|---|---|
| hello | `hello.asm` (the bring-up's M0) | `hello.bas` | `text.lua` — rows decoded through the font |
| first contact | `fujitest.asm` | `arm.bas`, `text.bas` | `txn.lua` — ACKSEQ, ERR, RXLEN, the reply; `text.lua` |
| netget | `netget.asm` | `netget.bas` | `text.lua` against the fixture file |
| directory | `fujidir.asm` | `dir.bas` | `text.lua` against the SD listing |
| boot | `fujiboot.asm` | `boot.bas` | `boottest.lua` — every served byte vs the file |
| appkey | `appkey.asm` | `appkey.bas` | `text.lua` — the shared name, and a written key read back |
| clock | `clock.asm` | `clock.bas` | `text.lua` |

`frames.lua` (Battleship's VSYNC tap) holds every BASIC program to 262-line
frames. `tools/snipcheck.py` builds every example in the reference chapters;
`tools/cmdcheck.py` requires a card for every command the firmware's RS232
dispatch tables and mixins answer.

### batari Basic

A batari Basic FujiNet client is one 2K bank (`set romsize 2k`) with the
cartridge's fixed half appended by `tools/bbfix.py`. The mailbox's names come
from the dasm headers (`fujinet.h`, `fujibas.h`, `netdefs.h`, `devdefs.h`);
every *value* is a `const`, generated into `fujiconst.bas` by
`tools/mkfujiconst.py` and prepended by `build.sh`, because batari Basic treats
an unknown name used as a value as memory. `fujitext.asm` is the minikernel
that shows the cartridge's text rows under the playfield. Section 8 of the book
has the rules and the measured row budget.
